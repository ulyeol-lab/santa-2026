# 🎄 2026 크리스마스 선물 타입 테스트 · 선물 추천 웹앱

파일 하나(`index.html`)만 있으면 끝나는 크리스마스 바이럴 웹앱입니다.
서버도, 빌드도, 데이터베이스도 없습니다. GitHub Pages에 `index.html` 하나만 올리면 바로 서비스됩니다.

## 구성
- **5문항 테스트**: "2026 크리스마스, 산타가 내게 줄 선물 타입은?" → 8가지 결과 타입
- **링크 공유가 1순위**: 결과 화면·펀딩 화면의 `🔗 인스타 스토리·카톡에 링크 바로 공유하기` → Web Share API(모바일에서 인스타·카톡이 바로 뜸), 미지원 브라우저는 링크 복사. `#r=타입코드` 해시로 친구 결과 화면도 열립니다
- **이미지 저장은 보조**: `📸 이미지로 저장하기` 작은 텍스트 링크 → 1080×1920 PNG 카드(결과 카드·위시 카드)
- **선물 펀딩(조르기) 링크**: 결과·선물 카드의 `조르기 🎁` → 닉네임·한마디·목표 금액·송금 링크가 URL 해시(`#wish=…`)에 담긴 초대장. 서버 없이 공유됩니다
  - 선물은 **추천 선물 그대로** 또는 **직접 입력**(선물 이름 + 선택: 쿠팡 상품 링크) 중에 고를 수 있습니다. 상품 링크는 쿠팡 주소(`coupang.com`·`coupa.ng`)만 받습니다
  - 친구가 보는 화면의 메인 버튼 `🎁 쿠팡에서 선물 가격·상세 확인하기 (파트너스)`는 항상 파트너스 링크로 연결되고, 올린 사람이 붙여넣은 상품 링크는 `🔗 올린 상품 링크 그대로 보기`로 따로 남습니다
- **선물 큐레이션**: 예산(전체/2만원 이하/3~5만원대/10만원대+) × 대상(나에게/연인/친구·동료) 필터 33개 상품

## 수익화 설정 (1분 작업)
`index.html`을 열고 `<script>` 맨 위의 `PARTNERS_LINKS`와 `AD_CONFIG`만 고치면 됩니다.

1. **쿠팡 파트너스 링크**
   - 기본값: 모든 상품이 쿠팡 검색 결과(`https://www.coupang.com/np/search?q=...`)로 연결됩니다.
   - `lptag`에 파트너스 회원 ID(`AF…`)를 넣으면 **검색 링크·상품 링크·직접 입력한 상품 링크** 모두에 자동으로 붙어 내 실적으로 잡힙니다.
   - 파트너스에서 상품 딥링크를 발급받으면 아래처럼 상품 id에 붙여넣으세요. 해당 상품만 딥링크로 연결됩니다.
     ```js
     var PARTNERS_LINKS = {
       deepLinks: {
         'bangsho': 'https://link.coupang.com/a/발급받은코드',
         'instax': 'https://link.coupang.com/a/발급받은코드2'
       },
       searchBase: 'https://www.coupang.com/np/search?q=',
       lptag: 'AF0000000',
       tracking: ''
     };
     ```
   - 상품 id는 각 상품 데이터(`GIFTS`)의 `id` 값입니다. `tracking`에는 모든 링크 뒤에 붙일 추적 파라미터를 넣을 수 있습니다(예: `subid=santa`).
   - 링크 우선순위: 딥링크 → 쿠팡 검색 링크(둘 다 `lptag`·`tracking` 적용)
2. **광고 (애드핏 / 애드센스)**
   ```js
   var AD_CONFIG = {
     adfit: { unitId: 'DAN-XXXXXX' },          // 카카오 애드핏
     adsense: { client: 'ca-pub-...', slot: '...' } // 구글 애드센스
   };
   ```
   둘 중 하나만 채우면 홈·결과·선물 화면의 `ADVERTISEMENT` 자리에 자동으로 광고가 들어갑니다. (둘 다 비워두면 안내 자리만 표시)
3. **사이트 주소**: 배포 주소를 `SITE_URL`에 넣으면 공유 링크가 항상 정확해집니다. (비워두면 접속 주소를 자동 사용)

쿠팡 파트너스 고지 문구는 홈·선물 화면 푸터와 **펀딩(친구가 보는) 화면**에도 들어 있습니다.

## 검증
- `node` 없이 esprima(Python)로 JS 파싱 검사 + Playwright/Chromium으로 5문항 완주 → 결과 링크 공유(클립보드·Web Share 양쪽) → 펀딩 만들기(추천/직접 입력) → 친구 화면 상품 버튼·커스텀 링크 → 공유 링크 재방문 복원 → 위시 카드 PNG → `PARTNERS_LINKS` 설정 주입(딥링크·lptag·tracking)까지 37개 항목 자동 테스트, 콘솔/페이지 에러 0건 확인.
